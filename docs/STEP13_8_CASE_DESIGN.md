## 1. 设计原则

- **σy 使用已批准 EXP 数据**（650=227 / 700=212 / 750=199 MPa）；E 用 EXP（171/141/119 GPa）；无任何伪造/反推
- **Pi_yield = P·Ro/(w·σy)** 目标值 {0.7, 0.85, 1.0, 1.15, 1.3, 1.5} × 3 温度 = 18 槽位，每槽 1 例
- Rm ∈ {80, 100, 120}（train 域几何，不引入新的 Rm150 test 纠缠）
- 兼容性：MODEL_B 均匀 case，材料/BC/mesh(medium 48×16×3)/step/输出与 v2 生成器完全一致（`generate_cases_v2.py` 的 `gen_inp` 直接可用，零改动）
- 约束：wall=2 ≥4 例、P≥30 ≥4 例、过渡区（0.8–1.2）与 >1 各至少部分
- **regime 标签为求解前预测**，仅作设计意图，不预先假定 Abaqus 一定产生塑性

## 4. 填补的训练空洞（STEP 13.7 gap 对照）

| 空洞 | 现状 | 本设计 |
|---|---|---|
| Pi_yield ∈ [0.8,1.2] | train 0 例 | +9 例 |
| Pi_yield > 1 | train 0 例 | +12 例 |
| P≥30 | train 3 例 | +5 例（其中 3 例 Pi>1.2 塑性候选、2 例过渡） |
| wall=2 | train 15 例 | +11 例（含过渡/塑性域） |

→ 补足后 train 将首次包含：elastic→near-yield→transition→moderate→strong plastic 的完整 Pi_yield 谱，位移的 regime-aware stage-1 分类器与 von Mises 高压外推将获得训练依据。

## 5. 去重证明

- 脚本对每个候选以 (T, P, Rm, Ro, w) 主键与 **300 例 dataset（222 v1 + 78 v3 均匀 MODEL_B）+ 298 v2 候选（含未求解的 220 例）** 全量比对，命中即剔除；最终 18 例**零重复**（脚本输出无 WARN）
- case_id 采用 v3 命名规约（U_<T>_P<P>_Rm<R>_Ro<O>_w<W>），P 均为整数（无点），ID 唯一
- 新增 P 值（16–39 的若干整数）为设计自由度，不违反任何现有规约
