## 7. 防数据泄漏策略

1. **划分规则保持确定性 + 向后兼容**（v2 规则只新增、不改旧）:
   - 新增: T_u=675 → train; T_u=725 → validation; 梯度 T_in=675 → train; T_in=725 → validation（沿用现有 T_in≥725 规则族）; Rm∈{90,110} → train; Rm∈{130,140} → validation; 蠕变 t=300 → train; t=3000 → test
   - 现有 150 例按 v2 规则重新分类结果与 v1 完全一致（新增规则只触及新轴值，不触及旧 case）— 规则审计通过
   - 旧 54 test 的"外推唯一性"保持: 新 test 全部位于 Rm≥130 / T≥725 / P≥25 / t≥1000 新外推区
2. **外推梯子**（train → validation → test）: T: 650/675 → 700/725 → 750; Rm: ≤120 → 130/140 → 150; P: ≤20 → — → ≥25; t: ≤300 → — → ≥1000
3. **材料身份一致性**: 675/725 插值 σy/E 是统一材料法则（同 650/700/750 实测）的一部分，三个划分共用 — 属于模型属性而非数据泄漏; 插值值记录为 D 级派生文件备查
4. **时间泄漏**: 蠕变 train 永不见 t≥1000; t=3000 只在 test
5. **无随机划分** — 不存在随机种子/洗牌泄漏通道; case_id 确定性命名
6. 重建顺序: 求解 → 后处理 → 合并 v1+v2 → **一次性重划分** → 覆盖 train/val/test; 禁止增量拼接划分文件
