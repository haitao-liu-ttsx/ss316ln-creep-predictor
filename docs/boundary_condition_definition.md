# SS316LN-N014 环形圆管 边界条件定义

日期: 2026-08-19
模型: 闭合 3D 环形圆管 (torus, 绕 Z 轴), C3D8R

---

## 1. 为什么需要约束

闭合环形圆管是**自由体**: 没有与任何支撑连接,载荷为内压(自平衡)+ 均匀温度场(无 CTE 时不产生应变)。若不约束,刚度矩阵奇异,求解失败。

需要消除:
- 3 个平动刚体模态 (t1, t2, t3)
- 3 个转动刚体模态 (w1, w2, w3)

**原则**: 最小约束,只消除刚体模态,不阻碍真实变形(环形管的膨胀/弯曲)。

---

## 2. 约束方案 (4 节点, 8 约束)

选择**内壁 4 个节点**(phi=0 截面位置, 即管截面最外点 θ 方向),θ = 0° / 90° / 180° / 270°:

```
*Boundary
A: U1, U3     (θ=0°,  内壁, 位置 (116, 0, 0))
B: U1, U2     (θ=90°, 内壁, 位置 (0, 116, 0))
C: U1, U3     (θ=180°,内壁, 位置 (-116, 0, 0))
D: U2, U3     (θ=270°,内壁, 位置 (0, -116, 0))
```

其中节点坐标 (R_major + R_inner = 116, 0, 0) 等。

### 2.1 刚体模态消除矩阵分析 (rank 验证)

刚体位移场: u = t + w × r

| 模态 | 由哪些约束消除 |
|------|--------------|
| t1 (X 平动) | A/B/C 的 U1 |
| t2 (Y 平动) | B/D 的 U2 |
| t3 (Z 平动) | A/C/D 的 U3 |
| w1 (绕 X 转动) | A/C/D 的 U3 (u3 = w1*y - w2*x, y/x 不同站给出独立方程) |
| w2 (绕 Y 转动) | A/C/D 的 U3 (同上) |
| w3 (绕 Z 转动) | A/B/C 的 U1 + B/D 的 U2 (u1 = -w3*y, u2 = w3*x) |

刚体约束矩阵秩 = **6** (pre_run_check.py 数值验证 PASS)。

### 2.2 为什么不是"固定整个圆管"

- 大量节点完全固定会阻碍环形管的真实径向膨胀,引入虚假约束应力;
- 4 节点 8 约束是最小可行方案,只钉住 6 个刚体模态;
- 约束点位于**内壁 phi=0 截面**,该处 U1/U2/U3 固定方向与环形管对称膨胀模式的位移方向正交,约束力趋近于零(见结果: P0 时 RF=0)。

---

## 3. 验证结果

| Case | 最大约束反力 (RF_max) |
|------|---------------------|
| P0 (无压力) | 0.0000 N ✅ (纯温度场不产生约束力) |
| PTEST (5 MPa) | 339.3 N (压力自平衡后残余,合理) |

P0 时反力为 0 证实约束不引入虚假应力;PTEST 时反力仅来自压力载荷的数值平衡残差,非约束人为力。
