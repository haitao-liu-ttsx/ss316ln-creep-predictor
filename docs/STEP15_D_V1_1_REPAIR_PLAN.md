## D.1 时间结构分析（决定性证据）

**POD 系数对 log10(t) 完美线性**：

| 模态 | 斜率均值 | 斜率 std（28 case） | 线性 R² |
|---|---|---|---|
| c1 | 48.12 | 0.047 | **1.000** |
| c2 | −0.376 | 0.0004 | **1.000** |
| c3 | −0.158 | 0.0002 | **1.000** |

**结论**：
1. c_i(T,P,geom,t) = g_i(T,P,geom) + d_i·log10(t) **精确成立**（R²=1.0，跨 case 斜率 std<0.05）
2. 时间斜率 d_i 对 case 几乎不变 → 可用**全局/近全局常数 d_i + 逐 case 截距 g_i**（最简结构）
3. **解析时间外推结构是最合理选择**：XGB 树对 t 的常数外推缺陷由此根治（C.2 的 3000h 失效直接归因于此）
