# STEP 19 应力坐标系定义（STRESS COORDINATE DEFINITION）

日期: 2026-08-20 | 性质: 审计文档（不训练、不冻结、不修改任何模型/数据）

## 1. 坐标系定义

- **全局坐标系**：Abaqus 默认全局笛卡尔 XYZ。所有 case 的 INP 中**无 `*ORIENTATION`**，
  S 张量分量即全局笛卡尔分量。
- **几何布置**：环形管（torus）轴线 = **Z 轴**；环向角 θ 在 XY 平面内，θ = atan2(y, x)；
  径向 e_r = (cosθ, sinθ, 0)（自环心向外）；轴向 e_z = (0,0,1)；环向切向 e_θ = (-sinθ, cosθ, 0)。
  （证据：INP 首节点 (128,0,0)、(126.9,16.7,0) 位于 XY 平面圆环上；案例 Rm=110, Ro=22, w=4 时
  外层半径 128 = Rm + (Ro−w)。与 production `_mesh()` 的 torus 重建完全一致。）

## 2. 应力张量定义（ODB 中的原始分量）

S（INTEGRATION_POINT，C3D8R 单积分点 = 单元质心，2304 个单元）：

| 分量 | 全局笛卡尔含义 |
|---|---|
| S11 | σxx |
| S22 | σyy |
| S33 | σzz |
| S12 | τxy |
| S13 | τxz |
| S23 | τyz |

## 3. 坐标转换方法（Global Cartesian → Cylindrical (r, θ, z)）

对每个单元质心，取 θ = atan2(y, x)，应用 σ_cyl = R σ_cart Rᵀ：

- σr   = S11·cos²θ + S22·sin²θ + 2·S12·sinθ·cosθ
- σθ   = S11·sin²θ + S22·cos²θ − 2·S12·sinθ·cosθ
- σz   = S33
- τrθ  = (S22 − S11)·sinθ·cosθ + S12·(cos²θ − sin²θ)
- τrz  = S13·cosθ + S23·sinθ
- τθz  = −S13·sinθ + S23·cosθ

## 4. 最终四个应力输出

| 输出 | 来源 | 说明 |
|---|---|---|
| σr（径向应力） | 转换 | 垂直于管壁环向面的径向正应力 |
| σθ（环向应力） | 转换 | 环向（hoop）正应力，压力容器主承载方向 |
| σz（轴向应力） | S33 直接 | 沿环轴方向正应力 |
| τ（面内剪应力） | **τrθ** | 管壁截面内的剪应力（r–θ 面），与环向承载一致；τrz、τθz 亦可从同一 S 张量导出（备选） |

**绝不直接拿 S12 当"面内剪应力"**：S12 是全局 xy 分量，与管壁局部方位无关；必须按上式
逐质心旋转。

## 5. 单位

- Abaqus 一致单位体系：**mm – N – s – MPa**（证据：*Elastic E = 155020 即 MPa；压力 MPa；坐标 mm）
- 应力输出单位：**MPa（N/mm²）**
- CEEQ：无量纲（等效蠕变应变），恒 ≥ 0

## 6. 正负号约定

- 拉应力为正、压应力为负（Abaqus 连续介质力学约定，转换保持）。
- 剪应力按标准张量符号；显示时如使用幅值需注明。
- CEEQ 定义：等效蠕变应变（Equivalent Creep Strain），恒非负。
